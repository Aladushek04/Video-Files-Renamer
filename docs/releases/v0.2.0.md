# Video Files Renamer 0.2.0

Обновление после 0.1.5: десктопный интерфейс на CustomTkinter и безопасный
запуск с проверкой обновлений Git. Ядро, CLI и TUI не меняли поведения.

## Главное

- Десктопный GUI: папка, источники и статистика слева, таблица ревью справа —
  с чекбоксами, выбором кандидата и правкой имени прямо в строке.
- Долгие операции идут в фоновых потоках и не подвешивают окно; Preview можно
  отменить кнопкой «Отмена».
- `launcher.py` перед запуском проверяет обновления Git и обновляет проект,
  только если рабочее дерево чистое. Сбой Git не мешает запуску GUI.
- Диалоги «Студии» и «Журнал переименований» с откатом доступны и в GUI.

## Добавлено

- GUI на CustomTkinter (`video_renamer/gui/`): сайдбар с папкой, статусами
  StashDB/FansDB/ThePornDB и статистикой; таблица с колонками «оригинальное
  имя», «кандидаты», «новое имя», «источник», «conf»; панель выбранной строки.
- Таблица виртуализирована: в памяти живёт только видимый пул строк, поэтому
  сотни файлов не просаживают прокрутку. Пока идёт первый тяжёлый скан,
  показывается skeleton-заглушка и прогресс-бар.
- Горячие клавиши GUI: `↑`/`↓` — выбор строки с автоскроллом, `Space` —
  одобрить или снять, `Ctrl+Enter` — применить, `F5` — Preview, `Esc` — снять
  выделение, `Ctrl+O` — выбрать папку.
- Отмена Preview: кнопка выставляет `threading.Event`, воркер останавливается на
  ближайшем checkpoint и не показывает ошибку.
- `TitleService` принимает `cancel_event`: обход папки (`iter_video_files`)
  прерывается на ближайшем шаге, а не после обработки всех файлов.
- `launcher.py`: `git fetch`, затем `git pull --ff-only` только при чистом
  рабочем дереве; таймаут и любая ошибка Git не фатальны. Флаги `--no-update` и
  `--update-dialog`, переменная `VIDEO_RENAMER_SKIP_UPDATE=1`; статус
  передаётся в окно и виден в сайдбаре.
- `scripts/start_gui.bat`: создаёт `.venv`, ставит `requirements/gui.txt` и
  запускает `launcher.py`.
- Пакет: extra `gui` (`customtkinter>=5.2,<6`), точка входа `video-renamer-gui`,
  `python -m video_renamer.gui`. `requirements/dev.txt` включает GUI-зависимости.

## Изменено

- Модель ревью (`video_renamer/ui/tui_model.py`) общая для TUI и GUI: фильтры,
  одобрение, выбор кандидата и правка имени ведут себя одинаково.
- Общий сценарий ревью вынесен в `core/review_actions.py`: TUI и GUI используют
  одну реализацию preview, apply с записью журнала, загрузки справочников и
  правил ручного имени. TUI пишет журнал в настраиваемый путь, как GUI.
- Добавлены тесты рискованной GUI-инфраструктуры: маршалинг фоновых потоков и
  отмена (`tasks`), виртуализация и переиспользование пула строк
  (`virtual_rows`), строка таблицы (`widgets`) и окно журнала с откатом
  (`dialogs`).
- README: раздел про десктопный интерфейс и launcher, обновлённая структура
  пакета и список документации.
- Версия пакета — 0.2.0.

## Исправлено

- Правило фильтра ревью осталось одно — `ReviewModel.matches`; GUI больше не
  держит третью копию условий фильтра.
- Отмена сканирования папки поднимает `OperationCancelled` в ядре, а не
  возвращает частичный список: GUI не спутает отмену с пустой папкой, CLI и TUI
  получают явный сигнал.
- Строка таблицы после перепривязки пула больше не теряет первый коммит имени
  из-за отложенного `FocusOut`.
- Убран повторный пересчёт пула при изменении размера таблицы.

## Установка

Нужен Python 3.10+ (проверено на 3.14) и Windows 10/11. Лицензия — MIT.

```powershell
# GUI: батник сам создаст .venv и поставит CustomTkinter
scripts\start_gui.bat

# или пакетом
python -m pip install -e ".[gui]"
video-renamer-gui

# без автообновления
scripts\start_gui.bat --no-update
python -m video_renamer.gui D:\Videos\PH
```

Ключи StashDB/FansDB/ThePornDB кладутся в `.env` или переменные окружения, как и
раньше. GUI работает без Git: `launcher.py` пропустит обновление и запустит окно.

## Обновление с 0.1.5

1. Обновите зависимости — добавьте extra `gui`:

   ```powershell
   python -m pip install -e ".[gui]"
   ```

   Если вы пользуетесь батником, достаточно запустить `scripts\start_gui.bat`:
   он сам доставит `requirements/gui.txt`.

2. Формат `rename_log.csv`, справочники, кэш и `.env` не изменились.
   Пересобирать студии и справочник имён не нужно.

3. Консольные команды и TUI не изменились:
   `video-renamer`, `video-renamer-tui`, `scrape-stashdb`, `scrape-performers`,
   `merge-studios`.

## Известные ограничения

- GUI требует CustomTkinter (`pip install -e ".[gui]"`); CLI и TUI работают без
  него. Полноценный GUI-тест с открытым окном требует рабочего стола — в
  автотестах проверяется только контроллер без Tk.
- Автообновление в `launcher.py` работает только в git-репозитории с
  upstream; в архиве или при локальных правках оно просто пропускается.
- Откат, как и в CLI, проверяет OSHASH и размер: изменённый файл не
  откатывается. Строки старого журнала требуют открытой папки.
- Ограничения 0.1.5 остаются: PHASH требует ffmpeg/ffprobe, справочник имён
  собирается командой `scrape-performers`, текстовые и эвристические строки не
  одобряются автоматически.
