# Video Files Renamer 0.1.5

Крупное обновление после 0.1.0: PHASH и несколько источников отпечатков,
откат переименований, расширенный TUI и локальный справочник имён исполнителей.

## Главное

- Поиск по PHASH для перекодированных файлов и одновременный поиск отпечатков
  в StashDB, ThePornDB и FansDB.
- Откат уже выполненных переименований из CLI и TUI с проверкой OSHASH и размера.
- TUI управляет скраперами студий, позволяет выбирать альтернативных кандидатов
  и править имя вручную.
- Локальный справочник имён исполнителей StashDB: имена отделяются от названия
  до определения студии, поэтому `Veronica Leal` больше не превращается в
  студию `VERONICA`.
- Новый формат `rename_log.csv` со старыми строками, корневой папкой, размером
  и откатом.

## Добавлено

- PHASH-поиск (перцептивный хэш, совместимый со Stash) для файлов без
  OSHASH-совпадения: `preview --phash`. Найденная по PHASH сцена всегда уходит
  на ревью и не одобряется автоматически.
- Поиск отпечатков одновременно в StashDB, ThePornDB и FansDB. Ключи
  `THE_PORNDB_API_KEY` и `FANSDB_API_KEY`, отключение вторичных источников —
  `--no-secondary`. Сбой вторичного источника становится предупреждением.
- Кэш отпечатков по каждому источнику и локальный кэш PHASH.
- Справочник имён исполнителей StashDB: `scrape-performers` собирает полную
  базу (114 769 записей) и компактный индекс (4,3 МБ). Preview вырезает
  известные имена до определения студии, fallback собирает актёров из
  справочника, а в текстовый поиск попадают канонические имена. Флаги
  `--names` и `--no-names`; TUI подхватывает индекс автоматически.
- TUI «Студии»: запуск StashDB, FansDB, ThePornDB и слияния справочников
  с журналом выполнения и отменой запущенного процесса.
- TUI «Кандидаты»: выбор альтернативной сцены из найденных кандидатов.
- TUI «Имя»: ручное редактирование имени с валидацией Windows.
- TUI: минимальный размер окна 140×40 и автозапуск консоли 150×45.
- Откат записанных переименований: `undo --list` и `undo --ids` (dry-run по
  умолчанию), экран журнала в TUI (клавиша `u`) с подтверждением. Откат
  проверяет OSHASH и размер, журнал не переписывает.
- Строки старого журнала без корневой папки откатываются только с `--root`
  и `--confirm-legacy`.

## Изменено

- Формат `rename_log.csv`: добавлены колонки `action`, `undoes`, `root`, `size`.
  Старый файл переносится в `rename_log.legacy.csv` при первой записи.
- Структура проекта: интерфейс — в `video_renamer/ui/`, скраперы — в
  `video_renamer/scrapers/`, тесты — по подпапкам, релизные заметки — в
  `docs/releases/`. Точки входа `video-renamer`, `video-renamer-tui`,
  `scrape-stashdb`, `merge-studios` не изменились; изменились пути для
  `python -m`: `video_renamer.ui.tui`, `video_renamer.scrapers.merge_studios`.
- README переписан: быстрый старт для Windows, безопасность, справка по
  командам.
- Код приведён к `ruff format`, добавлена конфигурация ruff
  (`line-length = 100`, `docs/` исключён из форматирования).
- TUI: окно выбора папки позволяет переходить в подпапки, на уровень выше,
  вводить путь вручную и выбирать любой каталог.

## Исправлено

- TUI: поле «Папка с видео» при запуске пустое, путь подставляется только
  после выбора или из аргумента командной строки.
- TUI: сбой записи `rename_log.csv` не скрывает результаты уже выполненных
  переименований.
- `apply` для `preview --recursive` сохраняет файл в его подпапке.
- Таблица TUI помещается в 140×40, заметка перенесена в нижнюю панель.
- `q` при непустой таблице спрашивает подтверждение выхода.
- После apply строки с ошибками остаются в таблице для повторной попытки.
- Журнал с неизвестным заголовком не дописывается: вместо нечитаемого файла
  возвращается ошибка.
- Справочник, кэш, `.env` и журналы CLI/TUI больше не зависят от текущей
  папки запуска.
- CSV сохраняет настоящий апостроф перед формульным префиксом и экранирует
  `note` от формул Excel.
- Понятные сообщения для регистра расширения и слишком длинного имени;
  исправлен текст подтверждения apply.
- Кнопка «Применить» блокируется, если одобренных строк нет, в том числе
  после ошибки preview.
- Эвристика: дефис в имени файла считается разделителем слов
  (`veronica-leal-title` → `Veronica Leal - Title`), при этом `full-hd` и
  `1080p` по-прежнему вырезаются целиком.

## Удалено

- Старый CLI `python -m video_renamer.core.clean_ph_names` с массовым
  переименованием без одобрения и проверки отпечатка. Используйте
  `video-renamer apply`. Функции очистки имён остаются для матчера.
- Неиспользуемые импорты в тестах.

## Обновление с 0.1.0

1. Обновите пакет и зависимости:

   ```powershell
   python -m pip install -e ".[tui]"
   ```

2. Соберите справочник имён (один раз, 2,5–3,5 минуты):

   ```powershell
   python -m video_renamer.scrapers.performers --apply
   ```

   Файлы `data/performers.json` и `data/performers_index.json` генерируются
   локально и не входят в репозиторий.

3. Первый `apply` сам перенесёт старый `rename_log.csv` в
   `rename_log.legacy.csv`. Для отката старых строк нужны `--root` и
   `--confirm-legacy`.

4. Если вы запускали модули через `python -m`, обновите пути:
   `video_renamer.ui.tui` вместо `video_renamer.tui`,
   `video_renamer.scrapers.merge_studios` вместо
   `video_renamer.merge_studios`. Консольные команды не изменились.

## Установка

Нужен Python 3.10+ (проверено на 3.14) и Windows 10/11. Лицензия — MIT.

```powershell
# TUI: батник сам создаст .venv и поставит Textual
scripts\start_tui.bat

# CLI без установки
python -m video_renamer.cli preview D:\Videos\PH --csv preview.csv

# Пакет
python -m pip install -e ".[tui]"
video-renamer --help
video-renamer-tui
```

Для PHASH нужны `ffmpeg` и `ffprobe`. Ключи StashDB/FansDB/ThePornDB кладутся
в `.env` или переменные окружения.

## Известные ограничения

- OSHASH совпадает только с точной копией файла; для перекодированных файлов
  нужен PHASH или текстовый поиск.
- PHASH требует ffmpeg/ffprobe и заметно медленнее OSHASH.
- ThePornDB не поддерживает `queryStudios`: его скрапер обогащает известные
  имена через `findStudio`.
- В справочнике имён используются только многотокенные однозначные имена и
  алиасы. Односложные имена и неоднозначные алиасы не распознаются.
- Справочник имён не входит в поставку: его нужно собрать командой
  `scrape-performers`.
- Если сцены нет в StashDB, строка остаётся эвристической и не одобряется
  автоматически.
