# Changelog

## 0.1.5 — 2026-11-11

### Добавлено

- Справочник имён исполнителей StashDB: команда `scrape-performers` собирает
  полную базу и компактный индекс, а preview вырезает известные имена до
  определения студии. Это исправляет случаи, когда первое слово имени
  совпадает с названием студии (`Veronica Leal` и студия `VERONICA`),
  улучшает fallback-разбор актёров и поисковый запрос. Флаги `--names` и
  `--no-names`; TUI подхватывает индекс автоматически.

- PHASH-поиск (перцептивный хэш, совместимый со Stash): для файлов без
  OSHASH-совпадения, флаг `preview --phash`. Найденная по PHASH сцена всегда
  попадает на ревью, без автоодобрения.
- Поиск по отпечаткам одновременно в StashDB, ThePornDB и FansDB (ключи
  `THE_PORNDB_API_KEY`, `FANSDB_API_KEY`; `--no-secondary` отключает
  вторичные источники). Сбой вторичного источника — предупреждение, не ошибка.
- TUI «Студии»: запуск StashDB, FansDB, ThePornDB и слияния справочников
  с журналом выполнения и отменой запущенного процесса.
- TUI «Кандидаты»: выбор альтернативной сцены из найденных кандидатов.
- TUI «Имя»: ручное редактирование имени с валидацией Windows.
- TUI: минимальный размер окна 140×40 и автозапуск консоли 150×45.
- Откат записанных переименований: команда `undo --list` / `undo --ids`
  (dry-run по умолчанию) и экран журнала в TUI (клавиша `u`) с подтверждением.
  Откат проверяет OSHASH и размер, журнал не переписывается.
- Строки старого журнала без корневой папки откатываются только с `--root`
  и `--confirm-legacy`.

### Изменено

- Формат `rename_log.csv`: добавлены колонки `action`, `undoes`, `root`, `size`.
  Старый файл переносится в `rename_log.legacy.csv` при первой записи.
- Структура проекта: интерфейс перенесён в `video_renamer/ui/` (`tui.py`,
  `tui_model.py`, `studio_tasks.py`, `tui.tcss`), слияние справочников — в
  `video_renamer/scrapers/merge_studios.py`. Тесты разложены по `tests/core`,
  `tests/scrapers`, `tests/ui`, `tests/cli`. Релизные заметки — в `docs/releases/`.
  Точки входа `video-renamer`, `video-renamer-tui`, `merge-studios` не изменились;
  изменились пути для `python -m`: `video_renamer.ui.tui`,
  `video_renamer.scrapers.merge_studios`.
- README переписан: быстрый старт для Windows, безопасность, справка по командам.
- Код приведён к `ruff format`; добавлена конфигурация ruff (`line-length = 100`,
  `docs/` исключён из форматирования). Функциональных изменений нет.

### Удалено

- Старый CLI `python -m video_renamer.core.clean_ph_names` с массовым
  переименованием: он переименовывал все строки без одобрения и без проверки
  отпечатка. Используйте `video-renamer apply`. Функции очистки имён
  (`clean_stem` и др.) остаются: ими пользуется матчер.
- Неиспользуемые импорты в тестах.

### Исправлено

- TUI: окно выбора папки позволяет переходить в подпапки, на уровень выше,
  вводить путь вручную и выбирать любой каталог, а не только стартовый.
- TUI: поле «Папка с видео» при запуске пустое с подсказкой «Выберите папку»;
  путь подставляется только после выбора или из аргумента командной строки.
- TUI: сбой записи `rename_log.csv` больше не скрывает результаты уже
  выполненных переименований.
- `apply` для `preview --recursive` сохраняет файл в его подпапке, а не
  отклоняет имя с подкаталогом.
- Таблица TUI помещается в 140×40: заметка перенесена в нижнюю панель.
- `q` при непустой таблице спрашивает подтверждение выхода.
- После apply строки с ошибками остаются в таблице для повторной попытки.
- Журнал с неизвестным заголовком не дописывается: вместо нечитаемого файла
  возвращается ошибка.
- Справочник, кэш, `.env` и журналы CLI/TUI больше не зависят от текущей
  папки запуска.
- CSV сохраняет настоящий апостроф перед формульным префиксом и экранирует
  `note` от формул Excel.
- Понятные сообщения для регистра расширения и слишком длинного имени;
  исправлен текст подтверждения apply.
- Кнопка «Применить» снова блокируется, если одобренных строк нет, в том
  числе после ошибки preview.
- Эвристика: дефис в имени файла теперь считается разделителем слов
  (`veronica-leal-title` → `Veronica Leal - Title`). Дефисы режутся после
  техмусора, поэтому `full-hd` и `1080p` по-прежнему вырезаются целиком.

## 0.1.0 — 2026-11-05

Первый публичный релиз.

### Добавлено

- OSHASH-совместимый отпечаток файла и поиск сцены в StashDB.
- Текстовый поиск по StashDB с оценкой названия, исполнителей, студии, даты
  и code; фильтрация мусорных имён.
- CSV-ревью: `preview` → правка `approved`/`new` → `apply`.
- Безопасное двухфазное переименование, проверка OSHASH/size, защита от
  path traversal, коллизий и зарезервированных имён Windows.
- SQLite-кэш ответов StashDB и офлайн-режим.
- Скраперы студий StashDB, FansDB и ThePornDB с чекпоинтом, докачкой,
  фильтрами и отчётом коллизий.
- Слияние нескольких справочников в один `data/studios.json`.
- TUI на Textual: выбор папки, прогресс, таблица, фильтры, одобрение и apply.
- `start.bat` и `start_tui.bat` для Windows.
- 248 тестов ядра + 2 headless-теста TUI (250 с установленным Textual).

### Известные ограничения

- PHASH и MD5 целого файла не реализованы; OSHASH находит только точные копии.
- ThePornDB не отдаёт список студий: используется `findStudio` по seed-именам.
- TUI пока не запускает скраперы и не позволяет выбирать альтернативных
  кандидатов.
